# Goat Chaos — Minecraft 1.20.4 (Fabric)

## Как получить готовый JAR автоматически через GitHub

1. Создай новый пустой репозиторий на GitHub.
2. Загрузи в него всё содержимое этой папки, обязательно включая скрытую папку `.github`.
3. Открой вкладку **Actions** и выбери **Build Goat Chaos**.
4. Нажми **Run workflow**, если сборка не запустилась автоматически.
5. После успешной сборки открой запуск workflow и скачай архив `goat-chaos-minecraft-1.20.4` в разделе **Artifacts**.
6. Распакуй архив и положи `.jar` в папку `.minecraft/mods`.

Нужны Minecraft **1.20.4**, Fabric Loader и Fabric API **0.97.2+1.20.4**.

Примечание: проект пока не проверен запуском в игре. Если Actions выдаст ошибку, пришли лог сборки.
